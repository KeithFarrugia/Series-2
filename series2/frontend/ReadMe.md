# D3.js Basic Visualisation Project

This is a minimal project designed to display data visualisations using **D3.js** served via a simple Node.js server.

### Before Running
Before running this project copy over the clones.json and lines.json generated by the rascal clone detector project to the root of this project
(same level as this ReadMe). After this is done you can go on and run the project.

### Getting Started

To run this project, you need to have **Node.js** installed on your system.

1.  **Install Node.js:**
    If you don't have it, download and install the latest version from [nodejs.org](https://nodejs.org/).

2.  **Run and Access the Server:**
    Navigate to the project directory in your terminal and execute the server file:
    ```bash
    node server.js
    ```
    The server start on `http://localhost:3000`. Copy and paste that into your chromium browser to access the frontend.

### Important Note on File Viewer
This functionality relies on the file system access api and needs a Chromium-based browser (like Chrome, Edge, or Brave) for this feature to work correctly. Without a chromium browser this visualisation will not work.
