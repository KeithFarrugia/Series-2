# Summary:
This project contains code clones of Type 1-4, used to test the precision and recall of our implemented 
rascal clone detectors.

# Note:
To use custom images instead of basic shapes for entities and effects in the 
simulation, add image files named `hero.png`, `mage.png`, `goblin.png`, `orc.png`, 
`slash.png`, and `cast.png` to the `res` directory. This does not affect the code, just the simulation
visuals.
